# Colorimeter for Optical Absorbance Measurement

An educational biomedical instrumentation project developed using Arduino Uno, an LED light source, and an LDR sensor to measure optical absorbance.

## Project Details
- **Institution:** Balochistan University of Engineering & Technology, Khuzdar
- **Department:** Biomedical Engineering
- **Course:** Biomedical Instrumentation-II (BME-361)

## Hardware Components
- Arduino Uno
- Red LED
- LDR sensor
- 16×2 LCD
- Resistors and potentiometer
- Breadboard and jumper wires

## Working Principle
The device measures light intensity passing through a sample and calculates optical absorbance using:

**A = log₁₀(I₀ / I)**

## Limitations
This is an educational prototype. It does not provide automatic calibration or clinical-grade measurements.
